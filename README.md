## Featured projects

### [SliceKNN](https://github.com/MoLoUiSsS/sliceknn) — 5G slice classification

Classifies 5G flows into **eMBB / URLLC / mMTC** and flags out-of-distribution traffic
with a k-distance anomaly detector.

`Python` `scikit-learn` `FastAPI` `SQLite` `Docker` `MLflow` `GitHub Actions`

- **96.94%** accuracy and **96.95%** macro F1 on the held-out test split
- **0.9139** anomaly ROC-AUC, **66.67%** TPR at 1% FPR
- 23 tests, tuned KNN pipeline, batch inference and prediction logging

### [SpectraCNN](https://github.com/MoLoUiSsS/spectracnn) — RF modulation classification

Identifies **BPSK / QPSK / 16-QAM / 64-QAM** from raw I/Q samples with a PyTorch 1D CNN.

`PyTorch` `CNN` `FastAPI` `TorchScript` `Docker` `MLflow` `GitHub Actions`

- **69.89%** mixed-SNR accuracy, **79.5%** at 10 dB
- Per-SNR evaluation, constellation demo and TorchScript serving
- 31 tests covering signals, model, API and training helpers
